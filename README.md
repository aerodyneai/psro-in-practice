# psrolab — Policy-Space Response Oracles in Practice

Companion code for the book *Policy-Space Response Oracles in Practice: Building
Game-Theoretic Multi-Agent Systems*. Every figure and table in the book is
generated by a script in this repository.

## Quickstart

```bash
pip install -e .            # Part I (numpy/scipy only)
pip install -e ".[rl]"      # Part II+ (torch, OpenSpiel)
pytest tests/               # smoke tests (<5s base; RL tests auto-skip without [rl])
```

> **V100/Volta GPUs:** recent default torch wheels (cu13x) dropped sm_70
> kernels. On the book's reference hardware install torch from the cu126
> index first: `pip install torch==2.13.0 --index-url
> https://download.pytorch.org/whl/cu126`, then `pip install -e ".[rl]"`.

Run PSRO on rock-paper-scissors in six lines:

```python
import numpy as np
from psrolab import run_psro
from psrolab.games import MatrixGame, MatrixGameSim, ExactMatrixOracle
from psrolab.meta_solvers import NashSolverLP
from psrolab.eval import ProfileEvaluator, restricted_exploitability

a = np.array([[0,-1,1],[1,0,-1],[-1,1,0]], float)
game = MatrixGame(payoffs=np.stack([a, -a]))
result = run_psro(MatrixGameSim(game), ExactMatrixOracle(game),
                  NashSolverLP(), ProfileEvaluator(1), n_iterations=5)
print(result.meta_strategies)   # -> [1/3, 1/3, 1/3] support: PSRO found Nash
```

## Layout

```
src/psrolab/
  psro.py            the PSRO loop (~100 lines; printed in full in Ch. 5)
  games/             MatrixGame, SimGame interface, matrix wrapper (+ OpenSpiel, pursuit-evasion later)
  oracles/           best-response oracles: exact (now), tabular-Q, PPO, diverse-PPO
  meta_solvers/      uniform, Nash-LP, support enumeration (now), alpha-Rank, CE/CCE, replicator
  baselines/         fictitious play (now); self-play, last-k (Ch. 12)
  eval/              empirical-game evaluator w/ caching; exploitability metrics
experiments/         one folder per book chapter; scripts emit CSVs + figures
tests/               invariant tests — must always pass
CLAUDE.md            build instructions for Claude Code (milestones M1–M6)
```
